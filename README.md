Power BI Sales Dashboard

I built this Power BI dashboard to track executive KPIs, analyze revenue trends, and measure product profitability. I uploaded the .pbix source file so you can download it and test the interactive cross-filtering and data models directly.

Technical Skills Demonstrated:

Custom DAX Measures: Wrote formulas using SUMX, RELATED, and DIVIDE to calculate Normalized Revenue, Total Units Sold, and real-time Profit Margins.
Relational Data Modeling: Connected raw sales, product, and store tables to enable dynamic, country-level filtering.
Executive UI/UX: Built a clean, focused layout utilizing clustered bar charts for profitability analysis and line charts for revenue forecasting.

How to Use:
1.Download the .pbix file from this repository.
2.Open the file in Power BI Desktop.
3.Interact with the country slicer and select individual chart elements to see the cross-filtering mechanics in action.
